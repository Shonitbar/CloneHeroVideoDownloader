# Contributing to Clone Hero Video Downloader

Thank you for considering contributing to the Clone Hero Video Downloader! Here's how you can help improve this project.

## How to Contribute

1. **Fork the Repository**
   - Fork the repository to your GitHub account

2. **Clone Your Fork**
   - Clone your fork to your local machine
   - `git clone https://github.com/YOUR-USERNAME/CloneHeroVideoDownloader.git`

3. **Create a Branch**
   - Create a branch for your feature or bugfix
   - `git checkout -b feature/your-feature-name` or `git checkout -b fix/your-bugfix-name`

4. **Make Your Changes**
   - Implement your changes
   - Make sure all existing tests pass 
   - Add new tests if applicable

5. **Commit Your Changes**
   - Use clear and descriptive commit messages
   - `git commit -m "Add feature: your feature description"`

6. **Push to Your Fork**
   - `git push origin feature/your-feature-name`

7. **Create a Pull Request**
   - Go to your fork on GitHub
   - Click "New Pull Request"
   - Select your branch and submit the pull request

## Development Setup

1. Install Python 3.6 or higher
2. Install the required packages: `pip install -r requirements.txt`
3. Run `setup.bat` to download and install ffmpeg

## Code Style

- Follow PEP 8 guidelines
- Keep code clear and well-documented
- Add comments for complex logic

## Testing

- Test your changes thoroughly before submitting a pull request
- Make sure the application works on Windows

## Reporting Bugs or Suggesting Features

- Use the GitHub Issues tab to report bugs or suggest features
- Provide as much detail as possible, including steps to reproduce bugs
- For feature requests, explain the use case and benefits

## Thank You!

Your contributions help make this project better for everyone!
